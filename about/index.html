About

CG Alert monitors public vendor pages across Pricing, Terms/SLA, DPA, Sub‑processors, and Status/Security. We run a two‑pass filter to remove noise (layout nits, analytics pixels, typos) and keep only material changes. For each alert, we produce a verifiable evidence card with the relevant snippet, canonical URL, timestamp, and SHA256 hash so legal and procurement can quickly audit and trace provenance.

Delivery is email‑only. No calls. Fully async. You can unsubscribe at any time using the link in any email, or write to ops@cg-alert.com.

Scope

  • Public pages only: Pricing, Terms/SLA, DPA, Sub‑processors, Status/Security.
  • Robots first: we respect robots.txt and sitemap.xml.
  • Evidence‑first: snippet + URL + timestamp + SHA256.
