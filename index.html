Security & Data Handling

  • Public sources only — no credentials, no scraping behind auth.
  • Minimal storage — snippet (≤300 chars), URL, timestamp, diff hash.
  • Transport security — HSTS, TLS, strict CSP, no 3rd-party scripts.
  • Opt-out within 72h — see Privacy.
  • Evidence integrity — immutable logs, ISO date, hash for audit.

Reliability & Compliance posture

  • P95 alert latency < 24h; False positive rate < 10%.
  • Backups — evidence cards stored with daily snapshots.
  • Incident response — /.well-known/security.txt contact.
  • DMARC/SPF/DKIM — enforced for outbound email delivery.
  • Data retention — export & deletion on request.
