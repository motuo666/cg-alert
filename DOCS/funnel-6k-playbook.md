# 6k 美元中客单增长漏斗（Playbook）

## 目标
- 以 $6,000/年 套餐为主力，获取足够多的客户，使年收入 ≥ $400,000。

## 漏斗关键节点
1. 访客 → 试用 / 订阅
2. 试用 / 订阅 → 合格线索 (MQL/SQL)
3. SQL → 付费 6k 客户
4. 续费 / 升级

## 需要的指标（建议在 Workers / 分析管线中埋点）
- 每日/每周访客数、试用注册数、SQL 数
- SQL → 付费转化率
- 每个阶段的流失原因（表单未完成、邮件未打开等）

## 自动化动作
- 对未完成试用 / 未完成支付的用户自动触发提醒邮件。
- 根据使用行为进行分层跟进（高意向 / 中意向 / 低意向）。
